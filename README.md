# Commi

Commi—short for community—is a map-based application helping
Nigerians explore areas to live based on their priorities.

## Vision

Help people compare locations using preferences such as:

- Electricity supply, including Band A classification
- Flood risk
- Road conditions
- Commute to a chosen destination
- Security indicators
- Neighbourhood infrastructure and amenities

The planned map will visualise how closely areas match a
user’s selected preferences, with a percentage-based match
score and heatmap.

Commi focuses on location suitability, rather than apartment
listings. Listings may be considered in a future expansion.

## Project status

In active development. Features described here are planned
and may change as research and implementation progress.

## Data approach

Commi will combine existing datasets, original research, and
community contributions.

Data coverage, freshness, and confidence will be communicated
alongside location insights as the product develops.

## Open development

The application is being developed in public. Selected
research, restricted datasets, personal information, and
credentials are excluded from this repository.

## Planned stack

- Web: Next.js and TypeScript
- Backend: Go
- Database: PostgreSQL
- Mobile, later: React Native and Expo

## Contributing

Commi welcomes ideas, bug reports, and improvements.
